\section{Theory}
The quantum Zeno effect will be demonstrated here by considering the evolution between polarization states. The basis states in this case are $\ket{H}$ and $\ket{V}$. An arbitrary linear polarization state, then, can be written as 
\begin{align}
    \ket{\psi} &= \cos(\theta)\ket{H} + \sin{\theta}\ket{V},
\end{align}
where $\theta$ is the angle of polarization. 

We then aim to calculate the magnitude of the state that transmits through the polarizer. Allowing the photon to interact with the polarizer is effectively ``measuring'' the state of the photon, which causes its wavefunction to collapse into $\ket{H}$. Thus, in other words, we want to calculate the magnitude of state projected onto the polarizer axis. Without loss of generality, we will assume the polarizer is set to the $\ket{H}$ axis.\footnote{If the polarizer set at a different angle $\alpha$, this is equivalent to rotating the polarization state by $-\alpha$.} The projection operator \cite{griffithsIntroductionQuantumMechanics2018} onto the $\ket{H}$ state is
\begin{align}
    P_H &= \ket{H}\bra{H}.
\end{align}
Thus, projecting the arbitrary linear polarization onto $\ket{H}$ gives
\begin{align}
    P_H \ket{\psi} &= \ket{H}\bra{H}(\cos(\theta)\ket{H} + \sin{\theta}\ket{V}) \nonumber \\
    &= \cos(\theta)\ket{H}.
\end{align}
The magnitude of this state is
\begin{align}
    \braket{\psi|\psi} &= \cos^2(\theta),
\end{align}
which gives the probability that a given photon is transmitted. If there is a stream of photons entering a detector, 
\begin{align}
    \braket{\psi|\psi} \propto \Gamma,
\end{align}
where $\Gamma$ is the coincidence count rate. Thus, the relation between the input and output count rate is given by
\begin{align}
    \Gamma(\theta) &= \Gamma_\text{max}\cos^2(\theta). \label{eq:onepol}
\end{align}
For classical theories of light as an electromagnetic wave, this relation considering $\Gamma \leftrightarrow I$ is also known as Malus's law \cite{hechtOptics2017}.

In this experiment, we wish to verify this relation is true for single photons as it traverses multiple polarizers, each collapsing the photon's wavefunction into its polarization direction. If there are $n$ polarizers set so that the angle $\theta$ between them is consistent, this is equivalent to projecting successively onto different polarization states. Thus, the coincidence count rate for $n$ polarizers with angle difference $\theta$ is
\begin{align}
    \Gamma(\theta,n) &= \Gamma_\text{max}\cos^{2n}(\theta).
\end{align}
In the case where the total angle difference is \qty{90}{\degree}, the relation between $n$ and $\theta$ is
\begin{align}
    \theta = \frac{\qty{90}{\degree}}{n} = \frac{\pi}{2n}.
\end{align}
This leads to expected expression for the coincidence count rate for the experiment \cite{kwiatExperimentalRealizationInteractionfree1995},
\begin{align}
    \Gamma(n) &= \Gamma_\text{max}\cos^{2n}\left(\frac{\pi}{2n}\right)\label{eq:ratevsn},
\end{align}
or equivalently,
\begin{align}
    \Gamma(\theta) &= \Gamma_\text{max}\cos^{\frac{\pi}{\theta}}(\theta).
\end{align}

It is critical to note that for increasing $n$, the rate of coincident photons also increases. Interestingly, for $n\rightarrow\infty$, $\Gamma\rightarrow\Gamma_\text{max}$, meaning that all photons pass through despite the initial and final polarization angles being \qty{90}{\degree} apart. Thus, the quantum Zeno effect predicts that as more polarizers are added, more of the photons will transmit through, as the more frequent observations force wavefunction collapse in the polarizer bases.

\section{Results}
This experiment was performed for up to 4 polarizers, set at equal angles from \qty{0}{\degree} to \qty{90}{\degree}. The coincidence count rate was recorded for each configuration, with the baseline dark counts subtracted (Fig. \ref{fig:countsvsn}). These data were fit to a modification Equation \ref{eq:ratevsn}, 
\begin{align}
    \Gamma(n) &= A \cos^{2n}\left(\frac{\pi}{2n}\right) + C,
\end{align}
with $A$ and $C$ free fit parameters. The model showed a fair fit, with $R^2 = 0.9952$ and reduced $\chi^2 = 4.2447$. However, physical size constraints limited the number of data points possible. 

Error analysis was performed assuming a Poisson distribution for the number of counts,
\begin{align}
    \sigma &= \sqrt{N},
\end{align}
and an error of \qty{0.5}{\degree} in the angles. The accidental count rate was also corrected for using the relation,
\begin{align}

\end{align}

The data fit to a linear function with free slope and intercept. The fitted slope is \qty{224(39)}{counts/\second/polarizer}. The quantum Zeno effect-free case predicts a zero slope in this case, as increasing $n$ does not increase the number of transmitted photons. However, we see the violation of the null hypothesis by \qty{5.80}\sigma, a strong violation. Thus, we observe evidence of the quantum Zeno effect.
